# Navigation principles

The documentation navigation is designed around decisions a reader needs to make:

- **What am I trying to evaluate?**
- **What gap was found and what evidence supports it?**
- **What capability is missing?**
- **Which remediation assets should I instantiate?**
- **What must I test?**
- **What evidence is enough for closure?**
- **What changed after re-evaluation?**

Folder structure is secondary. Pages may remain deep in the repository for reproducibility while the rendered site exposes a smaller, task-oriented entry hierarchy.
