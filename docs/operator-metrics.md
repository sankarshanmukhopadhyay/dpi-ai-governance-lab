# Operator utility metrics

The programme measures whether evaluations lead to implementable and verifiable improvement.

| Metric | Meaning |
| --- | --- |
| Publications evaluated | Breadth of evidence base |
| Material gaps identified | Diagnostic output |
| Recurring capability clusters | Generalizable governance weaknesses |
| Artifact coverage | Gaps with at least partial reusable remediation |
| Standardized remediation coverage | Gaps with mature reusable remediation |
| Partial coverage | Priority areas for artifact development |
| Evidence-backed closure | Gaps whose acceptance criteria pass with evidence |
| Re-evaluation delta | Measured improvement after remediation |

Repository volume, document count, and schema count are supporting indicators, not programme success metrics.
