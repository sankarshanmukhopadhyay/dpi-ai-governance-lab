# Evaluations

This section collects TRACE outputs that matter for cross-publication learning and operator improvement.

## What belongs here

- real publication reviews;
- normalized `governance-gaps.yaml` registers;
- cross-review gap clusters;
- remediation coverage baselines;
- re-evaluation deltas after implementation.

## Current evidence baseline

The first operator-oriented baseline re-expresses three existing substantive reviews through the governance-gap contract:

- DPI-AI Framework 2026;
- Preparing India for AI Adoption;
- UNESCO AI Maturity Framework.

See [First real-review governance gap baseline](../baselines/2026-08-22/README.md).

## Reading review results

A TRACE review is diagnostic evidence. A governance gap is the normalized handoff to implementation. An artifact mapping is a remediation recommendation. Closure requires deployment evidence and re-evaluation.

These stages should not be collapsed into a single conformance claim.
