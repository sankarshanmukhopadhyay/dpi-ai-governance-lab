# Methodology glossary (v1.0)

## TRACE
**TRACE (Trust, Risk, Architecture & Conformance Evaluation)** — the Lab’s named method for assessing DPI–AI systems, programs, and policies.

## Review Package
A structured folder under `reviews/YYYY-MM-DD-<paper-slug>/` that contains the required outputs defined in `methodology/evaluation-contract.md`.

## Audit Trail
Evidence and rationale records that allow an external reviewer to verify how scores were assigned.

## Evidence pointer
A specific location reference (section, page, figure, table) plus a short supporting snippet (≤ 25 words) when needed.

## Explicit vs inferred
- **Explicit**: directly stated in the paper
- **Inferred**: derived by interpretation across statements; should be minimized and clearly marked
