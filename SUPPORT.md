# Support

Use GitHub Issues for reproducible experiment, control, evidence, documentation, publication, or governance-model defects and bounded proposals. Include the affected revision/experiment, expected and observed behaviour, and the smallest useful evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

This lab owns its experimental implementations, evidence capture, and bounded judgments. External regulatory, institutional, specification, and deployment authorities retain their own decision rights.
