# Versioning policy

## TRACE method version
The TRACE method version is recorded in `TRACE_VERSION`.

## Methodology docs
Methodology documents in `methodology/` follow semantic versioning:
- PATCH: clarifications, examples, typo fixes
- MINOR: rubric tweaks that preserve dimension set and scale
- MAJOR: dimension changes or scoring scale changes

## Recording in reviews
Each review MUST record the methodology and rubric versions used in `reviews/<...>/README.md`.
