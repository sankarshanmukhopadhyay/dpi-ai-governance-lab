# Repo alignment (Lab ↔ Artifacts)

## Purpose
The Lab repository produces **evaluations** using TRACE; the Artifacts repository ships **operational governance packs**.

## Primary linkage
- Artifacts repo: schemas, templates, conformance/evidence bundles
- Lab repo: review methodology + paper/system evaluations + calibration examples

## Cross-links (to maintain)
- Lab README SHOULD link to Artifacts adoption guides and TRACE alignment docs.
- Artifacts README SHOULD link to Lab methodology and review outputs (as examples).

## TRACE acronym
TRACE stands for **Trust, Risk, Architecture & Conformance Evaluation**.
