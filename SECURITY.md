# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Instead, report privately using one of the following channels:

- **GitHub Security Advisories** (preferred): create a private report in the repository's *Security* tab.
- **Email**: send details to `security@YOUR-ORG.example` (replace with a real mailbox for your fork/org).

Include:
- What you found and where (file path, command, reproduction steps)
- Expected vs observed behavior
- Any proof-of-concept or exploit notes (if safe to share)

## Response expectations

- **Acknowledgement**: within **3 business days**
- **Triage**: within **7 business days**
- **Fix / mitigation**: target within **30 days** for high-severity issues (best-effort)

If you need a coordinated disclosure timeline, state that explicitly.

## Supported versions

Security fixes are applied to the latest released version on the default branch.
