# Reviews

Paper-by-paper reviews produced using the DPI AI Governance Lab’s TRACE method.

## TRACE (what it stands for)
**TRACE (Trust, Risk, Architecture & Conformance Evaluation)** — the Lab’s named method for DPI–AI assessments.

## Stable review package format (v1.0)
All new reviews SHOULD follow the Review Package contract and templates:

- Contract: `methodology/evaluation-contract.md`
- Workflow: `methodology/review-workflow.md`
- Rubric: `methodology/scoring-rubric.md`
- Templates: `templates/`

A Review Package lives at:

`reviews/YYYY-MM-DD-<paper-slug>/`

…and contains:

- `README.md`
- `01-summary.md`
- `02-methodology-application.md`
- `03-scorecard.md`
- `04-audit-trail.md`
- `05-alignment-mapping.md`

## Batches

- `2026-02-20-paper-batch/` — Reviews for four governance/strategy papers (India AI adoption, DPI-AI framework, UNESCO maturity framework, AI sovereignty).
- `2026-02-22-ukri-strategic-framework-batch/` — UKRI AI Research and Innovation Strategic Framework (published 19 Feb 2026).

## Templates & examples

- `_template/` — A ready-to-copy review package skeleton.
- `_examples/` — Example outputs to demonstrate the methodology and file layout.
