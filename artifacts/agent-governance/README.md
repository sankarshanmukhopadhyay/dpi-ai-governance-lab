# Agent governance artifacts

This directory contains practical templates for governing **agentic AI**: systems that can use tools autonomously, spawn sub-agents, preserve state, and trigger real-world side-effects.

Key objectives:
- **Registration**: every operational agent is known, owned, and revocable.
- **Mandate**: every agent operates under explicit authority boundaries.
- **Containment**: stop-rights and rapid shutdown are real, tested mechanisms.
- **Monitoring**: post-deployment behavior is continuously observable.

See also: `annexes/reference-bibliography.md` and the conformance profile `artifacts/conformance-profiles/profile-agentic-action.md`.
